# Gobbl 0.1.4

Gob now works along with Grok, and Codex setup says what it needs.

- Grok Build: connect it in Settings → Agents and Gob follows Grok sessions live, with the coding and thinking faces and a cheer when a task finishes. Works whether you run Grok in a terminal or through an editor or desktop app. Thanks to Jash Jacob for this one
- Codex: Codex runs only hooks you've trusted. After you connect it, Gobbl now shows the one step left: in Codex, run /hooks (or open Hooks in Codex's settings in your editor) and trust Gobbl's hooks
- An interrupted or failed agent turn no longer gets a cheer
- Codex set up with an older Gobbl cheers on every finished turn again, not only the first one
