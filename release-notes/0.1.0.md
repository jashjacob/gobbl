# Gobbl 0.1.0

The first public release of Gobbl, a free, open-source notch app for Mac with a pet.

- Notch shelf for files, clipboard history, Now Playing with lyrics, calendar with Join links, focus timer and quick tools
- A pet that lives in the notch: moods, eyes that follow your cursor, typing along with you, Matrix rain while AI agents code
- Claude Code and Codex in the notch, with Allow and Deny for Claude Code permission requests
- The Gobbl key (right Option): tap to write or rewrite anywhere, double-tap for edit mode, hold to dictate
- On-device Whisper dictation: your voice never leaves your Mac
- Chat in the notch with reminders, a morning brief and an evening wrap
- Memory (opt-in beta): automatic to-dos, people and projects, day digests, search by meaning and memory chat, all stored on your Mac
- MCP connector: one switch connects your memory to Claude, ChatGPT, Cursor, VS Code, Gemini and more
- Automatic updates
