# Gobbl 0.1.3

Gob now follows Codex as closely as Claude Code.

- Codex connects through its lifecycle hooks, so Gob sees prompts and tool use as they happen: the coding and thinking faces while Codex works, not just a note when a turn ends
- Codex permission requests can reach the notch's Allow and Deny, when approvals are on
- Works alongside other tools that use Codex's notify command, instead of competing for it
- Already connected Codex? Turn it off and on again in Settings → Agents to switch to hooks
