# Gobbl 0.1.5

Codex no longer stops to ask when it isn't supposed to.

- Gobbl asked you to Allow or Deny Codex's tools even when Codex was running in an auto or bypass mode, and Codex waited on that answer. Sessions that approve their own tools now run straight through, untouched
- Notch approvals for Codex are only set up when you turn on "Approve permission prompts from the notch", and that switch now covers Claude Code and Codex together
- Already connected Codex? Turn it off and on again in Settings → Agents to apply this
