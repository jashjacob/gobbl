# Gobbl 0.1.1

Memory chat got much smarter about questions on your own day.

- Chat now plans what to look up before answering: which days, apps, sites, chats and people your question is about, then looks that up in memory on your Mac
- Ask "what did I do today", "who did I talk to on WhatsApp", "how long was I in Chrome this morning", "what did Samar say" or "when did I last see the invoice"
- Follow-ups work ("and on Telegram?"), and so do typos
- Answers say plainly when memory was off, paused, or started after the time you asked about, instead of guessing
- Day digests only say something was done when the screen showed it was
- If AI was turned off by the service, Settings shows Turn On again instead of a false On
